# KPIs
## 1. Login Success Rate
Percentage of successful logins compared to total attempts.

## 2. API Response Time
Average time the server takes to respond to requests.

## 3. Error Rate
Percentage of failed or invalid requests.

## 4. Active Users
Number of users interacting with the system.

## 5. Feature Usage
How often key features (e.g., search, messaging) are used.
